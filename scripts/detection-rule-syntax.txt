Aurora detection rule condition syntax (LogEventService -> DetectionEngine)
============================================================================

After a log event is saved, every enabled rule whose RuleStatus name is ACTIVE is evaluated.
Use OR to combine clauses (case-insensitive OR).

Clause forms
------------
1) message CONTAINS 'text'
   Case-insensitive substring on the log message. Inside quotes use '' for a literal quote (SQL style).

2) raw CONTAINS 'text'
   Same, on raw_data (JSON string) if present.

3) message ~ 'regex'
   Java regex; Pattern is compiled with find() on the message. Example:
   message ~ '(?i)-enc.*[A-Za-z0-9+/]{80,}'

4) raw ~ 'regex'
   Regex on raw_data.

5) Fallback
   If a clause does not match the patterns above, the whole clause (optional '...' quotes) is searched
   as a case-insensitive substring in the message.

Alert message template (Rule.alertMessage)
------------------------------------------
Placeholders: {message}, {hostname}, {agentId}

Disable engine
----------------
application.properties:
  aurora.detection.enabled=false
