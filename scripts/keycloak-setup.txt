Keycloak quick setup for Aurora (development)

1a) Run Keycloak - use port 8180 so Aurora can stay on 8080
   - Install JDK 17+ and set JAVA_HOME if Keycloak does not start.
   - PowerShell (from the Keycloak folder, e.g. C:\Users\igorv\Downloads\keycloak-26.6.1):
       $env:KEYCLOAK_ADMIN="admin"
       $env:KEYCLOAK_ADMIN_PASSWORD="admin"
       .\bin\kc.bat start-dev --http-port=8180
   - Admin UI: http://localhost:8180/

1b) Run Keycloak (Docker):
   docker run -p 8180:8080 -e KEYCLOAK_ADMIN=admin -e KEYCLOAK_ADMIN_PASSWORD=admin quay.io/keycloak/keycloak:26.0 start-dev

2) Open the admin console at http://localhost:8180/ (log in with the admin user you set above).






3) Create realm: "aurora"

4) Create client:
   - Client ID: aurora-spa
   - Client type: OpenID Connect
   - Access type / capability: PUBLIC client
   - Standard flow (authorization code): ON
   - PKCE: required (default for public clients in recent Keycloak)
   - Valid redirect URIs:
       http://localhost:4200/callback
       http://localhost:4200/*
   - Web origins:
       http://localhost:4200

5) Create at least one test user in realm "aurora" (Users -> Add user -> set password).

6) Backend application.properties:
   - aurora.security.permit-all=false
   - spring.security.oauth2.resourceserver.jwt.issuer-uri=http://localhost:8180/realms/aurora
   (no trailing slash on the issuer)

7) Frontend src/environments/environment.development.ts:
   - authEnabled: true
   - keycloakIssuer: same URL as issuer-uri above
